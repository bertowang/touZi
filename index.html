投资理财：从产品到证据

面向爱好买股票、基金、ETF 的计算机专业学生的一本投资理财教材。全书不按「入门技巧」拼盘，而沿现金 → 产品 → 定价 → 组合 → 盘面 → 证据 → 执行 → 风险 → 复盘一条主线展开：交易 App 上的每个入口都被还原成现金流权利、数据字段与可检验的假设。每章给出原理、公式、可运行的 Python 分析脚本与自绘 SVG 图。

本书的主张

投资是一套可验证的工程系统：目标是规格说明书，产品是接口，定价是折现算子，组合是带协方差正则的优化，盘面是事件流的可视化，策略是对历史数据的假设检验，实盘是带成本与延迟的部署。

每章学习闭环固定为四步：读模型 → 跑代码 → 改参数 → 写结论；脚本用固定随机种子生成合成数据，打印可手算核对的数值，并画出可提交的 SVG 图。

风险提示与免责声明：本书为教学材料，所有行情、净值、回测与图表均为合成数据或模型示意，不构成任何投资建议、产品推荐或收益承诺。历史表现与回测结果不代表未来收益；杠杆、衍生品、跨境与场外产品可能导致本金全部损失。真实投资须遵守所在市场的法律法规、投资者适当性管理、券商与基金销售机构的风险揭示，并自行承担决策后果。

运行 Python 示例（30 秒）

  1. 需要 Python 3.8+，不需要安装任何第三方包：示例只用 math、random、statistics 等标准库，以及仓库内的 tools/chart.py（纯标准库 SVG 绘图）。
  2. 直接运行某一章脚本：python3 part1/03-product-map/code/03-products.py；或从页面代码块右上角「复制」。
  3. 批量运行并生成全书插图：./tools/run_python.sh；只跑某几个：./tools/run_python.sh part3/16-candlestick/code/16-candle.py。
  4. 页面代码块与磁盘 code/*.py 由 tools/extract_code.py 自动同步，永远一致。
给程序员的代码契约
  • 零依赖：OLS、二叉树定价、回测引擎、绩效归因全部手写展开，方便对照公式。
  • 自包含：行情与净值由代码里的模型合成，不下载、不读外部数据文件。
  • 可复现：固定 random.seed(7)；参数集中在 # ---- 参数区 ----。
  • 有图有真相：每章脚本打印数值并写出 fig/*.svg，浏览器直接查看。
  • 可批量验证：./tools/run_python.sh 跑完全部脚本；python3 tools/check_book.py --run 把实跑纳入自检。

为什么不用 numpy / matplotlib？教材要展示的是算法本身与「图是怎么画出来的」。附录 A.6 给出手写实现与工业库的对照表，学完之后应能无缝切换。

学习路线（建议两个学期）

  1. 第一阶段 · 共同语言与产品地图（00～08）：复利与实际收益、风险度量、可交易产品分类、交易规则、账户费用、OHLCV 数据模型、基金 ETF、固收与现金管理。
  2. 第二阶段 · 定价、组合与资产配置（09～14）：债券久期、DCF 估值、指数与套利、期权 payoff、均值-方差、再平衡与生命周期。
  3. 第三阶段 · 盘面语言与看图识图（15～20）：订单簿、K 线与复权、均线趋势、指标公式、形态判定、SVG 画图与未来函数。
  4. 第四阶段 · 从直觉到可验证的证据（21～28）：因子模型、行为偏差、资金拥挤、论文复现、数据管道、回测引擎、绩效归因与多重检验。
  5. 第五阶段 · 实盘、风险与长期主义（29～31、附录）：执行成本、仓位与杠杆上界、IPS 与年度复盘。

时间有限时的最短路径：00 → 01 → 03 → 13 → 16 → 20 → 21 → 26 → 28 → 30 → 31。
